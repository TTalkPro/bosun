# bitcask 13.1.2 → 13.2.0

## 背景
bitcask 13.2.0 只动了**图层**（`graphdb` / `graphdb_adj`：新增图层布局 2，每组边在 KV 上组织为 B+ 树，新库缺省布局 2）。
libbitcask、KV 盘上格式与 C/C++ ABI 均不变。bosun 只用 bitcask 做全文检索（`open` / `put` / `get` / `delete` / `search_fields` /
`search_wildcard` / `merge` / `status` / `list_keys` / `encode_meta` 等），不碰 `graphdb` / `bitcask_cypher`，接口与行为不变，既有索引直接可用。

## 做了什么
- `rebar.config`：tag `13.1.2` → `13.2.0`（仍按 `git_subdir` 取 `apps/bitcask`）。`rebar.lock` 不变：bitcask 走 `_checkouts`，checkout 依赖不进 lock。
- `designs/08-search.md` 的依赖写法同步。

## 验证
- `rebar3 check`（xref、dialyzer、eunit 81、ct 8）全过；编译走 `_checkouts` 的 bitcask 工作区，该工作区停在 tag `13.2.0`（f3ec8b6）。
- **干净拉取也验过**：`docker compose build` 按 `git_subdir` 从 GitHub 拉 13.2.0，cmake 编出 `bitcask_cpp.so`，镜像构建成功（上次 13.1.2 没做这一步）。
  只构建了镜像，没有替换正在运行的容器。

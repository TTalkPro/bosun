# bitcask 13.1.1 → 13.1.2

## 背景
bitcask 13.1.2 是 PATCH：只把内嵌的 libbitcask 从 13.1.1 升到 13.1.2，外加 `vsn` 与文档。
libbitcask 这一段的库源码逐字节相同（只改了版本号、上游自己的测试与记录），bitcask 的 Erlang / NIF 源码也没变，
所以 bosun 用到的接口（`open` / `put` / `get` / `delete` / `search_fields` / `search_wildcard` / `merge` / `status` 等）
签名与行为都不变，盘上格式不变，既有索引直接可用。

## 做了什么
- `rebar.config`：tag `13.1.1` → `13.1.2`（写法不变，仍按 `git_subdir` 取 `apps/bitcask`）。`rebar.lock` 不变：
  bitcask 走 `_checkouts`，checkout 依赖不进 lock。
- `designs/08-search.md` 的依赖写法同步。

## 验证
- `rebar3 check`（xref、dialyzer、eunit 63 个、ct 7 个）全过；编译走 `_checkouts` 的 bitcask 工作区，该工作区正停在 tag `13.1.2`。
- 按 `git_subdir` 从 GitHub 真实拉取 13.1.2 的路径，在 litegate 同日的升级里验过（同一 tag、同一写法）：子模块初始化、NIF 编出、
  litegate 的 eunit 全过。bosun 这边没有另做不带 `_checkouts` 的拉取。

## 注意
Docker 镜像同样走 `git_subdir` 拉取，这次没有跑 `docker compose build`。

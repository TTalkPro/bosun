# Bosun 功能列表

Bosun 是给**人和 AI Agent 一起用**的项目进度 / 任务管理：人用网页，Agent 经 MCP 接入，两边看到的是同一份任务、同一套规则。
本文按模块列出全部功能；截图见 [README](../README.md#截图)，版本变化见 [CHANGELOG](../CHANGELOG.md)，设计细节见 [`designs/`](../designs/)。

## 1. 组织与账号

| 功能 | 说明 |
|---|---|
| 注册组织 | 任何人用邮箱验证码注册一个组织，注册人是管理员；验证码 6 位、15 分钟有效，可重发（倒计时） |
| 登录 | 邮箱 + 密码，会话 Cookie；记住邮箱、大写锁定提示；被限流时按钮倒计时 |
| 组织隔离 | 项目、任务、筛选器、操作者都属于组织；别的组织的数据一律「不存在」（含检索与统计） |
| 用户管理（管理员） | 建账号（邮箱 + 显示名 + 初始密码）、停用 / 恢复、改角色、重置密码；组织里至少保留一个管理员 |
| 账户页 | 个人资料、改密码、主题（浅 / 深 / 跟随系统）与主题色、默认视图等偏好、我的工作 |
| API key | 每个用户给自己的 Agent / 脚本建 key（`bsk_…`，明文只显示一次）；权限 `read` / `write` / `manage`，可限定项目白名单与过期日；可撤销、可安全轮换（旧秘密立即失效，权限与历史保留） |
| 限流 | 登录、发验证码、改密码按来源 + 邮箱限流（429 + `Retry-After`），反向代理后可信任 `X-Forwarded-For` |
| 署名 | 网页上的操作署登录用户；Agent 署 `identify` 的名字并记在 key 主人名下；绑定了 key 的会话不能冒名 |

## 2. 项目

| 功能 | 说明 |
|---|---|
| 项目 Key | 2–10 位大写字母 / 数字，字母开头；成为任务编号前缀（`BOS` → `BOS-1`），创建后不可改 |
| 新建项目 | 先名称后 Key；Key 自动转大写，实时预览任务编号 |
| 项目设置 | 概况（任务 / 未结 / 已验收 / Epic、完成度）、名称、Key（只读可复制）、Markdown 描述；未保存的修改关闭前确认 |
| 归档 | 危险区按钮 + 确认；归档后不接受新任务、默认隐藏，已有任务仍可操作；可取消归档 |
| 项目列表 | 卡片（名称、Key、描述、未结 / 已验收、更新时间）、统计卡片与近 14 天新建 / 完成图；可显示已归档 |

## 3. 任务

| 功能 | 说明 |
|---|---|
| 编号 | 项目内自增：`BOS-12`，大小写不敏感 |
| 字段 | 标题、Markdown 描述、优先级（高 / 中 / 低）、标签、执行人、提出人、类型（任务 / Epic）、所属 Epic、所属 Milestone、提交、状态历史、反馈 |
| 新建 | 两栏面板：类型卡片、标题、描述 + 属性栏（优先级、Epic、Milestone、执行人、标签）；Ctrl / ⌘ + Enter 创建；「创建后继续新建」连续录入（清空标题与描述、保留属性） |
| 快速添加 | 看板列底部直接输标题回车；「更多选项…」带着标题打开完整面板 |
| 行内编辑 | 详情页标题、描述、优先级、执行人、标签、Epic、Milestone 直接改 |
| 执行人 | 可预派；谁把任务改成进行中谁就是执行人；选择器可搜索，也可直接输入 Agent 的名字 |

## 4. 状态与验收

| 状态 | 可以去 | 说明 |
|---|---|---|
| 新建 | 进行中、已拒绝、已撤销 | |
| 进行中 | 已完成、已拒绝、已撤销 | 被未完成的依赖挡住时不能开始 |
| 已完成 | 已验收、进行中（打回） | 完成时记提交 hash 与测试证据（命令 / 是否通过 / 摘要） |
| 已验收 | 进行中（重新打开） | 执行方**自己验收**必须有通过的测试记录；提出方或第三方验收不需要 |
| 已拒绝 | 新建（重新提交） | 执行方认为需求不对 |
| 已撤销 | 新建（恢复） | 不需要了 / 被替代；不是拒绝 |

- 看板上拖到「已完成」「已拒绝」等需要说明的状态时，先弹证据 / 说明面板。
- 每次迁移写进状态历史（谁、何时、备注、提交、测试）。

## 5. 反馈

- 四种：说明（comment）、评审（review）、提问（question）、回答（answer）。
- **不可变**：作者修订 = 追加新版本、旧版本作废，线索完整；反馈编号 `BOS-12#3`。
- 最新一条有效反馈是提问时，任务标「有提问待回答」，详情页有提示条和「去回答」。
- 详情页动态流里内联输入（Ctrl / ⌘ + Enter 发送），也可以展开 Markdown 编辑器。

## 6. Epic

- `kind = epic` 的任务是一个整体目标，其它任务用「所属 Epic」挂上去作为步骤（可跨项目）。
- 进度由步骤派生（已完成 + 已验收 / 不含已撤销）；步骤全部完成 Epic 自动置为已完成，步骤重开会把 Epic 拉回进行中。
- Epic 详情里步骤可看列表或看板，可直接新建步骤。

## 7. 关联：依赖与替代

- **依赖**（A depends_on B）：B 没到已完成 / 已验收之前 A 不能开始；成环拒绝；被挡住的任务标「被阻塞」，详情页列出挡路的任务。
- **替代**（A replaces B）：A 接手 B，B 若还在新建 / 进行中会自动撤销。
- 关联可删，删除不改状态。

## 8. Milestone（发布范围）

| 功能 | 说明 |
|---|---|
| 规划 | 每次发布先建 milestone（名称、开始 / 目标日期、说明），把任务排进去；一次发布可含若干 Epic 与独立任务 |
| 状态 | 规划中 → 进行中 → 已发布；进行中可暂停回规划中，已发布可重新打开；**每个项目同时只有一个进行中** |
| 排期入口 | 新建任务（缺省为当前看的 milestone）、任务详情、看板卡片 / 列表行菜单、列表勾选批量；Epic 下新建的步骤缺省跟 Epic 进同一个 |
| Epic 跟随 | Epic 换 milestone 时，原来跟它在一起、还没做完的步骤一起移动 |
| 变更留痕 | 每次移入 / 移出 / 发布结转 / 跟随 Epic 都记录（谁、何时、从哪到哪、原因）；移出或换 milestone 时可写原因；milestone 的「范围变更」面板和任务动态流里都能看到 |
| 进度口径 | 完成率 = 已完成 + 已验收 / 范围（不含 Epic、已拒绝、已撤销）；另列待验收、Epic 完成数 |
| 发布 | 发布面板：交付数、其中待验收、没做完的去向（规划中的 milestone / 当场新建 / 退回待规划）、按 Epic 分组自动生成可改的发布说明；已完成未验收的算交付；发布记录保存快照 |
| 燃尽 | 每天剩余未完成数（按变更记录回放，中途移入 / 移出都算准）+ 到目标日的理想线；已发布的停在发布时的剩余 |
| 管理页 | `/projects/:key/milestones`：进行中置顶、规划中按目标日期、已发布折叠；开始 / 暂停 / 发布 / 重新打开 / 编辑 / 删除（仅规划中且没有任务） |
| 侧栏 | 项目名下单独一行子项：进行中的 milestone、进度条与百分比，点了进它的看板 |

## 9. 看板与列表

- **范围切换**：页头 milestone 切换器（进行中 / 规划中 / 已发布 / 待规划 / 全部任务），写进链接。**看板只在选中某个 milestone 时提供**（缺省是进行中的那个）；待规划和全部任务只有列表；没有进行中的 milestone 时缺省进待规划列表。
- **概况卡片**（选中 milestone 时）：日期、还剩几天 / 已超期、完成率、未开始 / 进行中 / 待验收 / 已验收 / Epic 完成，右侧燃尽图；已发布的显示发布记录与发布说明。
- **看板**：按状态分列，拖拽改状态（鼠标、触屏、键盘），乐观更新；列折叠、只看某列、列内快速添加；工具条按执行人 / 优先级 / 需要关注（被阻塞或待回答）筛选、按优先级 / 更新 / 创建 / 编号排序；卡片显示优先级、标签、Epic、阻塞 / 待回答、反馈数、提交数、执行人。
- **列表**：列显隐（含 Milestone 列）、列头排序、分页与每页行数、执行人 / 优先级分面、行菜单（打开、复制 ID、Milestone、优先级）、勾选整页批量设置 Milestone。
- 搜索框（全文 + 编号子串）、状态筛选、任务 / Epic 切换都写进链接，刷新不丢。

## 10. 任务详情

- 页头：编号、类型、状态、优先级、Milestone、阻塞 / 待回答标记；面包屑带项目与 Epic；上一个 / 下一个任务；状态迁移按钮。
- **提示条**：被依赖挡住时列出挡路任务（解释为什么不能开始）；有提问待回答时给摘录与「去回答」。
- **进度卡片**：新建 → 进行中 → 已完成 → 已验收，每步谁在何时推进、当前步已持续多久、打回次数；拒绝 / 撤销时显示终止步与原因。
- **交付卡片**：最近一次测试证据（通过 / 未通过、命令、摘要）与全部提交（可复制）。
- 右栏属性、关联卡片；动态流把状态变化、Milestone 变更、反馈按时间合在一起。

## 11. 检索与 BQL

- **全文检索**：标题 / 描述 / 标签 / 反馈，中英文（jieba 分词 + BM25），跨项目；顶栏全局搜索下拉。
- **BQL**（JQL 风格，完整参考见 [BQL.md](BQL.md)）：项目、编号、状态、优先级、标签、提出人、执行人、类型、Epic、阻塞、依赖 / 替代、Milestone、Milestone 状态、标题、描述、全文、反馈、创建 / 更新时间、待回答、反馈数；`AND / OR / NOT`、`IN`、`IS EMPTY`、`ORDER BY`。
- 查询页：CodeMirror 编辑器（高亮 + 按上下文补全字段与取值）、结果概览（按状态 / 优先级 / 项目分布，可点选追加条件）、最近运行、导出 CSV。
- **筛选器**：保存的查询，侧栏一键打开。

## 12. 统计

- 项目列表页 / 项目页统计卡片：未结、进行中（含被阻塞数）、待验收（含待回答提问数）、近 7 天完成（环比），近 14 天新建 / 完成柱图。
- 选中 milestone 时统计只算这个 milestone，并给燃尽图。
- 组织页：团队负载（每人负责的未结任务）、用户与 Agent 列表。

## 13. Agent 接入（MCP）

- `/mcp`（Streamable HTTP），只认 `Authorization: Bearer <api key>`；工具 / 资源 / 提示按组织与 key 的项目白名单过滤，按 key 的权限授权。
- **工具（28）**：身份 `identify` `whoami` `list_actors`；项目 `list_projects` `get_project` `create_project` `update_project`；任务 `list_tasks` `search_tasks` `get_task` `create_task` `update_task` `transition_task` `link_tasks` `unlink_tasks`；Milestone `list_milestones` `get_milestone` `create_milestone` `update_milestone` `transition_milestone` `assign_milestone`；反馈 `add_feedback` `update_feedback` `list_feedback`；查询 `query_tasks` `list_filters` `save_filter` `delete_filter`。
- **资源**：`bosun://projects`（含各项目进行中的 milestone）、`bosun://workflow`（协作工作流）、`bosun://bql`（BQL 速查）。
- **提示**：`work_on_task`——把任务全文、工作流规则和「在不在当前发布里」一起放进上下文。
- 错误信息面向 Agent，告诉它下一步该怎么做。协作规则见 [AGENT-WORKFLOW](AGENT-WORKFLOW.md)（英文版 [AGENT-WORKFLOW.en](AGENT-WORKFLOW.en.md)）。

## 14. REST

- 前端用的全部接口也对脚本开放（Cookie 会话或 Bearer key）；Bearer key 打写接口时按权限拦截（任务协作要 `write`，项目 / milestone / 筛选器管理要 `manage`）。
- 错误统一 JSON：`{error, message, field?, detail?}`，状态码 400 / 401 / 403 / 404 / 409 / 413 / 429。
- 端点清单见 [README](../README.md#rest)。

## 15. 导入导出

- 管理员在「数据导入导出」页导出本组织 JSON，或导入（合并 / 替换）；导入前先**预演**，预览将新增 / 覆盖 / 跳过 / 删除多少。
- 文件内容逐条校验（形状、归属、序号只进不退）；别的组织占用的项目 Key 拒绝；筛选器按规则去重；导入后每个项目仍只能有一个进行中的 milestone。
- 命令行：`scripts/export.sh` / `scripts/import.sh`（读 `BOSUN_API_KEY`）。

## 16. 界面

- shadcn / Tailwind，参照 shadcn dashboard 风格；浅色 / 深色，多种主题色。
- Markdown：Milkdown（Crepe）编辑器，GitHub 风格渲染，Mermaid 图。
- 侧边面板统一：短表单窄、带大段 Markdown 的宽；表单标签 / 控件 / 说明间距一致。
- 响应式：窄屏侧栏收起；看板支持触屏拖拽。

## 17. 部署与运维

- 单个 Erlang release，同一端口提供页面、REST、MCP；数据在 Mnesia，检索索引可随时从 Mnesia 重建（索引格式变了启动时自动重建）。
- 升级时表结构按字段名自动迁移。
- 部署方式：`bin/bosun foreground`、systemd、FreeBSD rc.d、Docker Compose（缺省端口 5000，数据挂宿主机目录）。
- 配置：数据目录、端口、SMTP（未配置时验证码打日志）、Cookie Secure、反向代理、限流参数，见 [README](../README.md)。
